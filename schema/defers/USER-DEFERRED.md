# Inbox — write here freely

A title and a sentence are enough. No schema, no identifier, no classification.

On the next run an agent converts what is here into queue items under `_todo/`,
backfills the classification, and empties this file. Do not do that work
yourself; the point of this file is that capture costs nothing.

Friction at capture time is the reason backlogs die.
