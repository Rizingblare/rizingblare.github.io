# 받은편지함 — 자유롭게 여기에 작성하세요

제목 하나와 문장 하나면 충분하다. `schema`, `identifier`, `classification`은 필요 없다.

다음 실행에서 에이전트가 여기에 있는 내용을 `_todo/` 아래의 대기열 항목으로 변환하고,
`classification`을 보완한 뒤 이 파일을 비운다. 그 작업을 직접 해서는 안 되며,
이 파일의 목적은 아무런 비용 없이 내용을 포착할 수 있게 하는 데 있다.

포착 단계의 마찰은 밀린 작업 목록이 사장되는 원인이다.

## English brief

This file is a zero-friction inbox: a title and one sentence are enough, with no `schema`, `identifier`, or `classification` required. On the next run, an agent converts its contents into queue items under `_todo/`, backfills `classification`, and empties the file; the user must not do that processing.
