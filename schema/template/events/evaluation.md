## Rules for this category

The verdict binds to pre-registered criteria **by reference** — a proposal's frozen
section, or a fixture identifier. Never restate the criteria here; a restated
criterion drifts toward the result.

Status is running or concluded. A verdict exists only when concluded, and the
criteria reference is immutable once it lands.

Which fixtures must run is decided by **binding, not declaration**. You describe
what the change touches, which you know; the mechanism derives what must be
re-verified, which you usually do not. Asked to declare it, an author names the
dependents they already had in mind — exactly the set that was never at risk.
