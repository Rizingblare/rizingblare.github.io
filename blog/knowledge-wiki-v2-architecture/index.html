1,399개 내부 커리큘럼을 공개 문서로 이어가는 지식 위키 구조

15개 분야의 내부 커리큘럼 목록 1,399개 중 현재 공개된 7개 문서를 탐색하는 방식을 소개합니다.

게시 2026.08.03갱신 2026.08.07
GitHub PagesKnowledge WikiStatic SiteLearning UX

작은 개념을 관계로 다시 연결합니다

내부 커리큘럼 목록 1,399개에는 짧은 정의, 비교가 필요한 주제, 표준, 법규, 시사 항목이 함께 있습니다. 각 개념을 작게 나누되 선행·대조·응용 관계로 다시 이어서 학습 흐름을 만듭니다.

세 가지 탐색 방법

  1. 분야별 탐색은 내부 커리큘럼의 15개 분야 가운데 공개 문서가 있는 3개 분야만 보여 줍니다.
  2. 학습 문서는 현재 공개된 7개 주제를 수식, 예시, SVG 실험으로 깊게 설명합니다.
  3. 전체 검색은 별칭까지 함께 찾아 익숙한 표현으로 같은 개념에 도달하게 합니다.

프레임처럼 분야에 따라 뜻이 달라지는 표현은 문맥을 나누고, 비트처럼 여러 분야에서 공유하는 개념은 관련 학습 자료로 이어 줍니다.

첫 화면을 가볍게 유지합니다

홈과 위키 인덱스에는 분야 요약과 최근 공개 문서만 보여 줍니다. 전체 개념 목록은 분야별로 나누고, 검색어를 입력했을 때 필요한 자료만 불러옵니다.

빌드 결과의 크기보다 사용자가 처음 받는 HTML과 DOM의 크기를 먼저 제한합니다.

다음 단계

다음에는 공개 문서와 상호작용형 시각화를 늘리고, 한 문서에서 관련 개념으로 자연스럽게 이어지는 학습 경로를 더 촘촘하게 다듬습니다.
