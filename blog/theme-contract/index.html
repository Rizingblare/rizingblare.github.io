Atlas와 Pixel 테마가 같은 컴포넌트를 바꾸는 방식

공통 구조 CSS와 테마 토큰 CSS를 분리해 사이트 전체 디자인을 교체하는 구조를 설명합니다.

게시 2026.08.02갱신 2026.08.03
CSSDesign SystemTheme

구조와 디자인을 분리합니다

페이지의 의미 구조와 접근성은 core.css와 공통 HTML 컴포넌트가 담당합니다. 선택된 테마는 같은 컴포넌트에 적용되는 색상, 경계선, 그림자와 형태를 토큰으로 바꿉니다.

공통 토큰

--paper
--ink
--line
--brand
--shadow
--viz-bg
--viz-text

Atlas는 문서 가독성과 넓은 여백을 기본값으로 사용하고, Pixel은 기존 포트폴리오의 단단한 테두리와 계단식 그림자를 선택 가능한 보조 테마로 유지합니다.

페이지별 별도 구현이 필요하지 않은 이유

이력서 카드, 프로젝트 카드, 위키 문서, 블로그 글은 서로 다른 콘텐츠 모델을 사용하지만 최종 컴포넌트는 동일한 토큰 계약을 따릅니다. 테마 선택은 localStorage에 저장되어 다음 페이지에서도 유지됩니다.
