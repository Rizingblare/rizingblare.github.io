모바일 지식 저장소 동기화 흐름

Termux·Git·Obsidian을 분리해 저장소 손상과 설정 충돌을 줄이는 구성

01

PROBLEM

ORIG_HEAD와 object 파일이 손상되거나 네트워크 오류로 pull이 중단되었습니다.

rsync가 로컬 .obsidian 설정을 삭제할 수 있었습니다.

02

DECISIONS

  • Git 작업 공간과 Obsidian 읽기 공간을 역할별로 분리했습니다.
  • 동기화 시 .obsidian을 제외하고 원격 강제 갱신 절차를 별도로 문서화했습니다.
03

OUTCOME

  • 저장소 복구와 일상 동기화 절차를 분리해 반복 오류 가능성을 줄였습니다.
