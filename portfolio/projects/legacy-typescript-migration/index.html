CASE STUDY / legacy-typescript-migration

C# 레거시 기능의 TypeScript 전환

동작을 보존하면서 사내 프레임워크의 책임 단위로 재구성

01

PROBLEM

레거시 코드의 분기와 DB별 예외가 한 메서드에 집중되어 있었습니다.

새 프레임워크의 프로그램 생명주기와 기존 로직의 실행 순서를 맞춰야 했습니다.

02

DECISIONS

  • 입력 변환·검증·조회·상태 변경을 별도 책임으로 분리했습니다.
  • 열거형과 타입을 사용해 문자열 상태값의 해석 범위를 좁혔습니다.
  • DB별 차이는 공통 계약 아래에서 분기하도록 정리했습니다.
03

OUTCOME

  • 기능 단위 테스트와 오류 위치 추적이 쉬워지고 후속 변경 범위가 명확해졌습니다.

공개 범위
고객사 정보와 사내 식별자는 공개하지 않고 문제 구조와 해결 원리만 정리했습니다.
