CASE STUDY / knowledge-wiki

개념 학습 위키와 GitHub Pages 구조

Markdown 문서, SVG 시각화, 개념 관계를 정적 사이트로 연결

01

PROBLEM

수천 개 문서가 쌓이면 폴더 구조만으로는 선행 개념과 관련 개념을 찾기 어렵습니다.

AI 에이전트가 작성하더라도 모든 문서가 동일한 메타데이터와 품질 기준을 따라야 합니다.

02

DECISIONS

  • 도메인·선행 개념·관련 개념·난이도·상태를 frontmatter 계약으로 고정했습니다.
  • 문서별 SVG를 정적 자산으로 생성하고 본문과 관계 그래프에서 재사용합니다.
  • 빌드 시 중복 slug와 끊어진 내부 링크를 검사하도록 구성했습니다.
03

OUTCOME

  • 이력서·포트폴리오와 같은 도메인에서 학습 기록을 별도 라우트로 제공하는 프로토타입을 완성했습니다.
