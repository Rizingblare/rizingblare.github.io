CASE STUDY / knowledge-wiki

개념 학습 위키와 GitHub Pages 구조

Markdown 문서, SVG 시각화, 개념 관계를 정적 사이트로 연결

01

PROBLEM

수천 개 문서가 쌓이면 폴더 구조만으로는 선행 개념과 관련 개념을 찾기 어렵습니다.

개념이 많아질수록 각 문서에서 무엇을 먼저 알고 어디로 이어서 학습할지 분명해야 합니다.

02

DECISIONS

  • 내부 커리큘럼 목록 1,399개를 15개 학습 분야로 구조화하고, 공개 문서가 있는 분야만 탐색 화면에 제공합니다.
  • 문서별 SVG 실험과 관계 그래프로 추상 개념을 직접 확인할 수 있게 했습니다.
  • 검색 별칭과 구성 개념 연결을 활용해 서로 다른 표현에서도 같은 학습 주제로 이어지게 했습니다.
03

OUTCOME

  • 내부 커리큘럼 목록 1,399개 중 현재 공개된 7개 문서를 3개 활성 분야에서 탐색할 수 있습니다.
